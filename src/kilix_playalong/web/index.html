Fret spacing is exact — fret n sits at 1 − 2−n/12 of the scale length, so the frets crowd as they climb. Strings are spaced evenly and graded by gauge. The chord name, the position box and the string order come from docs/FRETBOARD.md, the definition this project holds both of its surfaces to.
